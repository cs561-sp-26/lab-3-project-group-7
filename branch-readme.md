## Summary of Work Done in This Branch
This branch adds global CSS utility classes to `style.css` to support consistent UI behavior across the application. These styles improve accessibility, layout control, and interaction states for common elements.

The changes include:
- Custom focus styling for keyboard accessibility
- Removal of inner border for buttons in Firefox (`::-moz-focus-inner`)
- Utility class for hiding elements (`.hidden`)
- Utility class for disabling interactions (`.disabled`)

This branch is also intended for demonstrating a **rebase workflow** with the `main` branch before final integration.
